## 한눈에 보는 현재 상태

| 항목 | 상태 |
| --- | --- |
| 엔드포인트 | **47개**, 전부 구현 (처음 31개 → 47개) |
| 자동 테스트 | **121개** 통과 (처음 14개) — `mvn test` |
| 인증 | 이메일·비밀번호 + JWT. 로그인·가입·헬스체크·Swagger 외 모든 API 에 토큰 필요 |

| AI | `AI_API_KEY` 가 있으면 OpenAI 호환 Tool Calling, 없으면 규칙 기반. 키가 있어도 크레딧이 없으면 규칙 기반으로 대신 답함 |

| **검증 안 된 것** | 실제 PostgreSQL 기동, Docker 이미지 빌드, 실제 LLM 답변 품질 → [07](07-현황과-남은-과제.md) 참고 |

## 30초 요약

- **이 앱이 하는 일**: `사용 가능 자금 = 현재 잔액 − 이번 달 아직 내지 않은 고정 지출`을 계산해 **자금 날씨**(맑음·흐림·비·폭풍)로 보여준다.
- **처음 코드의 문제**: API 는 다 있었지만 몇 개는 이름과 다르게 동작했다. 반복 규칙이 반복하지 않았고, 잔액이 고정값이었으며, 인증이 없었고, AI 가 질문을 읽지 않았다.
- **지금**: 위 문제를 모두 고쳤고, 인증·잔액 원장·Tool Calling AI·배포 구성을 더했다. 리팩토링으로 824줄짜리 서비스를 역할별로 나눴다.
