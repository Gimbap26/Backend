## 무엇을 어떻게 검증했나

| 대상 | 방법 | 결과 |
| --- | --- | --- |
| 전체 API 동작 | 자동 테스트 121개 (H2, PostgreSQL 호환 모드) | ✅ 전부 통과 |
| 실제 서버 | jar 를 띄워 스크립트로 27개 항목 점검 (인증, 잔액, 예측, CORS, 로그아웃, 로그인 제한, 페이징 등) | ✅ 27/27 |
| API 응답 예시 | 47개 엔드포인트 + 오류 7종을 실제 호출해 [03](03-API-명세.md)에 반영 | ✅ |
| 외부 AI 요청 형식 | 가짜 AI 서버로 Tool Calling 흐름·`tool_call_id` 짝·이력·폴백·5회 제한 | ✅ |
| 외부 AI 자동 선택 | 실제 키를 환경 변수로 넣고 기동 → `openai-compatible` 선택 확인 | ✅ |
| 운영 프로필 안전장치 | `JWT_SECRET` 없이 `postgres` 프로필 기동 → 기동 실패 확인 | ✅ |
| 리팩토링 | 테스트 파일을 고치지 않고 117개 통과, 엔드포인트 47개 동일, 실제 서버 점검 결과 동일 | ✅ |
| **실제 PostgreSQL** | 개발 PC 에 Docker 가 없어 실행하지 못함. PostgreSQL 에서 달라질 수 있는 SQL 은 코드로 검토만 함 | ❌ **미검증** |
| **Docker 이미지 빌드** | 같은 이유 | ❌ **미검증** |
| **실제 LLM 답변** | OpenAI 계정 크레딧 소진(`insufficient_quota`)으로 모든 호출이 거절됨 → 규칙 기반 대체 답변은 정상 | ❌ **미검증** |

### 첫 배포 때 할 것

```bash
docker compose -f docker-compose.prod.yml up -d --build
docker compose -f docker-compose.prod.yml logs app | grep -E "Successfully applied|AI 답변기|Started MoneyWeather|ERROR"
curl http://localhost:8080/actuator/health
```

`Successfully applied 5 migrations`, `Started MoneyWeatherApiApplication`, health `UP` 이면 PostgreSQL·Docker 미검증 항목이 해소됩니다.
크레딧 충전 후에는 `POST /agent/chat` 응답의 `provider` 가 `openai-compatible`(폴백 아님)인지 확인하세요.

## 알려진 문제

문서를 쓰면서 실제 응답과 코드를 다시 확인해 찾은 것들입니다. K1·K2는 09번에서 해결했습니다.

| # | 문제 | 영향 | 제안 |
| --- | --- | --- | --- |
| K1 | **해결됨**: PATCH 본문 검증 없음 | 거래·예정 이벤트·반복 규칙 PATCH에 validation 적용 | [09](09-남은-검증-과제-정리와-입력-검증-보완.md) |
| K2 | **해결됨**: `MONTHLY` 규칙을 `dayOfMonth` 없이 만들 수 있음 | 생성·수정 시 `MONTHLY`면 `dayOfMonth` 필수로 400 | [09](09-남은-검증-과제-정리와-입력-검증-보완.md) |
| K3 | **검증 메시지 언어가 서버 설정을 따름** | 로컬(한국어 Windows)은 "0보다 커야 합니다", Docker 서버는 영어일 가능성 큼 | 기본 로케일을 `ko` 로 고정하거나 메시지를 직접 지정. 프론트는 `fields` 의 키로 판단 |
| K4 | 오류 메시지 언어가 섞여 있음 | 403·404 일부는 영어(`Resource owner does not match current user.`), 나머지는 한국어 | 한국어로 통일 |
| K5 | 일부 응답의 필드 순서가 호출마다 다름 (`Map.of`) | 기능 영향은 없음. 응답을 눈으로 비교할 때 헷갈림 | 필요하면 `LinkedHashMap` 이나 record 로 |
| K6 | 날짜가 지난 `SCHEDULED` 이벤트를 "앞으로 낼 돈"으로 계산 | 결제 완료 처리를 안 하면 사용 가능 자금이 계속 낮게 나옴 | 연체 표시 또는 사용자에게 결제 여부 확인 |
| K7 | 잔액 변경 이력 없음 | 잔액이 왜 이렇게 됐는지 추적 불가 (특히 직접 수정) | 필요해지면 원장 저널 테이블 ([04 D5](04-의사결정-기록.md#d5-잔액-효과는-저장하지-않고-되돌리기--변경--적용)) |
| K8 | `api_request_logs` 가 계속 쌓임 | 장기 운영 시 DB 용량 | 보관 기간 정해 주기적 삭제 |
| K9 | `/actuator/prometheus` 인증 없이 공개 | 인터넷에 직접 노출하면 메트릭이 보임 | 프록시에서 차단하거나 인증 필요로 |
| K10 | 로그아웃이 모든 기기에 적용 | 기기별 로그아웃 불가 | 필요하면 refresh token 도입 ([04 D10](04-의사결정-기록.md#d10-토큰-무효화-사용자별-토큰-버전)) |
| K11 | 카테고리 이름 중복을 DB 가 아닌 앱에서만 막음 | 동시 요청 시 드물게 중복 가능 | `(user_id, name)` UNIQUE 추가 (V6) |
| K12 | OpenAI API 키가 작업 중 AI 대화 기록에 노출된 적 있음 | | **키 교체 권장**. 코드·설정 파일에는 키가 없음 (환경 변수로만 사용) |
