# 05. DB 스키마

스키마는 **Flyway 마이그레이션만으로** 만들고, Hibernate 는 `ddl-auto: validate` 로 엔티티와 스키마가 맞는지 **검사만** 합니다. 엔티티와 SQL 이 어긋나면 서버가 기동하지 않습니다.

## 규칙

- **이미 적용된 마이그레이션 파일(V1~V5)은 절대 고치지 않는다.** 배포된 DB 는 이미 적용된 파일을 다시 실행하지 않고, 파일 내용이 바뀌면 Flyway 체크섬 오류로 기동이 멈춘다. 바꿀 것이 있으면 `V6__설명.sql` 을 새로 만든다.
- H2(개발)와 PostgreSQL(배포) **둘 다에서 도는 SQL** 만 쓴다. H2 는 `MODE=PostgreSQL` 로 띄운다.
- `TEXT`/`@Lob` 대신 큰 `VARCHAR` 를 쓴다 ([04 D15](04-의사결정-기록.md#d15-큰-문자열-컬럼은-text-가-아니라-큰-varchar)).
- 컬럼을 추가하면 엔티티 필드도 함께 추가하고, 서버를 한 번 띄워(`mvn clean test`) 검증을 통과하는지 본다.

## 마이그레이션

| 버전 | 파일 | 내용 |
| --- | --- | --- |
| V1 | `V1__init_schema.sql` | 처음 스키마: 사용자, 계좌, 카드, 카테고리, 거래, 예정 이벤트, 반복 규칙, 월 예산, 예산 한도, AI 대화·메시지 |
| V2 | `V2__observability.sql` | `api_request_logs` |
| V3 | `V3__recurring_and_card_links.sql` | 거래↔카드, 이벤트↔규칙·카드 연결 + 자동 생성 중복 방지 UNIQUE |
| V4 | `V4__auth_ledger_agent.sql` | 인증(email, password_hash, 가입자 ID 시퀀스), 잔액 원장(각 테이블의 account_id, accounts.version), AI 근거(tool_trace, content 확장) |
| V5 | `V5__token_version.sql` | `users.token_version` (로그아웃·비밀번호 변경 시 토큰 무효화) |

## 관계

```
users
 ├─ accounts ──────────────┐ (결제·입금 계좌)
 ├─ cards ── payment_account_id ─→ accounts
 ├─ categories             │
 ├─ transactions ── category_id → categories
 │                ── card_id → cards
 │                ── account_id, transfer_account_id → accounts
 ├─ recurring_rules ── account_id → accounts
 ├─ financial_events ── recurring_rule_id → recurring_rules   (반복 규칙이 만든 것)
 │                    ── card_id → cards                       (카드 청구)
 │                    ── account_id → accounts                 (결제 완료 시 반영할 계좌)
 ├─ monthly_budgets
 │    └─ budget_category_limits   (category_name 으로 카테고리를 "이름" 참조, FK 아님)
 └─ agent_conversations
      └─ agent_messages

api_request_logs   (user_id 는 FK 아님. 로그라서 사용자가 지워져도 남김)
```

## 테이블

표시: **굵게** = 처음 스키마 이후 추가된 컬럼

### users
| 컬럼 | 타입 | 설명 |
| --- | --- | --- |
| id | BIGINT PK | 시드 사용자 1번, 가입자는 `users_id_seq`(1000부터) |
| name | VARCHAR(255) | |
| base_month | VARCHAR(7) | 기준 월 `yyyy-MM`. 기간을 안 주면 이 달로 계산 |
| status | VARCHAR(32) | `ACTIVE` / `INACTIVE`. 비활성이면 토큰이 거부됨 |
| **email** | VARCHAR(255) UNIQUE | 소문자로 저장 |
| **password_hash** | VARCHAR(255) | BCrypt |
| **token_version** | INTEGER, 기본 0 | 토큰에 담기는 값. 올리면 기존 토큰 전부 무효 |

### accounts
| 컬럼 | 타입 | 설명 |
| --- | --- | --- |
| id, user_id | | |
| bank_name, account_name, purpose | VARCHAR | |
| balance | BIGINT | 거래·결제 완료로 자동 증감 ([02](02-구조와-핵심-개념.md#잔액-원장-ledgerservice)) |
| included_in_assets | BOOLEAN | false 면 사용 가능 자금 계산에서 제외 (예: 적금) |
| **version** | BIGINT | 낙관적 잠금 (`@Version`) |

### cards
| 컬럼 | 설명 |
| --- | --- |
| card_company, card_name | |
| payment_day | 결제일 1~31 (없는 날은 말일) |
| active | 삭제 대신 false |
| **payment_account_id** | 대금이 빠질 계좌 → 청구 이벤트가 물려받음 |

### categories
| 컬럼 | 설명 |
| --- | --- |
| name | 같은 사용자 안에서 중복 금지(앱에서 검사, DB 제약은 없음) |
| category_type | `INCOME` / `EXPENSE` / `TRANSFER` |
| system_default | true 면 삭제 불가 (가입·시드 때 만드는 4개) |

### transactions — 실제 있었던 거래
| 컬럼 | 설명 |
| --- | --- |
| transaction_date, merchant, amount, transaction_type | |
| category_id | 없으면 미분류 |
| **card_id** | 카드 거래 (다음 달 청구액에 합산) |
| **account_id** | 계좌 거래 (잔액 즉시 반영). card_id 와 동시에 값이 있을 수 없음(앱에서 검사) |
| **transfer_account_id** | 이체의 받는 계좌 |

인덱스: `(user_id, transaction_date)`, card_id, account_id, transfer_account_id

### financial_events — 앞으로 있을 입출금
| 컬럼 | 설명 |
| --- | --- |
| event_date, title, amount, direction, event_type | |
| status | `SCHEDULED` / `PAID` / `CANCELED` |
| fixed | true 면 고정 지출(사용 가능 자금에서 미리 뺌) |
| **recurring_rule_id** | 반복 규칙이 자동 생성한 이벤트 |
| **card_id** | 카드 청구 자동 생성 이벤트 |
| **account_id** | 결제 완료 시 잔액을 바꿀 계좌 |

UNIQUE: `(recurring_rule_id, event_date)`, `(card_id, event_date)` — 자동 생성 중복 방지. 두 컬럼이 NULL 인 수동 이벤트는 H2·PostgreSQL 모두 제약에 걸리지 않는다.

### recurring_rules
| 컬럼 | 설명 |
| --- | --- |
| title, amount, event_type, direction | 생성될 이벤트의 값 |
| recurrence_type | `MONTHLY` / `WEEKLY` / `YEARLY` |
| day_of_month | MONTHLY 의 날짜 |
| start_date, end_date | 이 기간 안에서만 생성 |
| active | 삭제 대신 false |
| **account_id** | 생성될 이벤트가 물려받음 |

### monthly_budgets / budget_category_limits
| 테이블 | 컬럼 | 설명 |
| --- | --- | --- |
| monthly_budgets | budget_month, total_limit_amount | `(user_id, budget_month)` UNIQUE |
| budget_category_limits | budget_id, category_name, limit_amount | **카테고리를 이름으로 참조.** 카테고리 이름을 바꾸면 앱이 함께 바꿈 |

### agent_conversations / agent_messages
| 테이블 | 컬럼 | 설명 |
| --- | --- | --- |
| agent_conversations | title, created_at | |
| agent_messages | role | `USER` / `ASSISTANT` |
| | content | **VARCHAR(20000)** (처음 4000) |
| | sources | 호출한 도구 이름, 쉼표 구분 |
| | **tool_trace** | VARCHAR(100000). 호출한 도구의 인자·결과 JSON (근거) |

### api_request_logs
user_id, method, path, status, duration_ms, client_ip, user_agent, created_at. `/actuator`, `/swagger-ui`, `/v3/api-docs`, `/h2-console` 요청은 기록하지 않습니다. **삭제·보관 기간 정책이 없어 계속 쌓입니다.**
