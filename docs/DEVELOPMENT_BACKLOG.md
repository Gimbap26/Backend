# Remaining Development Backlog

기능 명세서의 API 는 모두 구현되어 자동 테스트(121개)로 검증되어 있습니다(`docs/FEATURE_COVERAGE.md`).
CORS, 토큰 무효화, 로그인 제한, DB 페이징, Docker 배포 구성까지 끝났습니다. 아래는 그 다음 단계입니다.

## 1. 첫 배포 때 확인할 것

| 항목 | 이유 |
| --- | --- |
| 실제 PostgreSQL 에서 기동 확인 | 테스트는 H2 의 PostgreSQL 호환 모드로 돌렸고, 개발 PC 에 Docker 가 없어 실제 PostgreSQL 로는 실행해 보지 못했습니다. README 의 "처음 배포한 뒤 한 번 확인할 것" 순서대로 로그를 확인하세요 |
| Docker 이미지 빌드 확인 | 같은 이유로 `Dockerfile` 도 실제로 빌드해 보지 못했습니다 |

## 2. AI

| 항목 | 현재 | 할 일 |
| --- | --- | --- |
| 실제 모델 연결 | 코드 완료, 가짜 서버로 검증 | API 키를 환경 변수로 넣고 실제 답변 품질 확인 |
| 프롬프트 관리 | system 프롬프트가 코드에 있음 | 버전 관리, 질문·기대 답변 모음(eval set)으로 회귀 확인 |
| 비용·지연 기록 | 도구 호출 시간만 기록 | 모델 호출 토큰 수·응답 시간 기록 |
| RAG / 파인튜닝 | 없음 | 절약 팁·금융 상품 문서 검색, 반복되는 실패 패턴이 쌓이면 파인튜닝 검토 |

## 3. 계정

| 항목 | 현재 | 할 일 |
| --- | --- | --- |
| 비밀번호 재설정 | 없음 (로그인한 상태에서 변경만 가능) | 메일 발송 수단(SMTP 등)이 정해지면 재설정 링크 방식으로 추가 |
